# 插镜与接点核对

把改动位置理解成「前镜末尾 → 新增或替换的画面 → 后镜开头」。相同方法可用于一个镜头，也可用于一整段分镜。需要先解决这三段如何连在一起，然后再决定取景、表演及声音。

## 读取两端状态

| 核对项 | 到前镜末尾和后镜开头各自查什么 |
| --- | --- |
| 环境与气氛 | 同一地点与时段是否接续，门窗和出入口位置，人和主光源的关系，天气、环境声、亮暗与安静程度 |
| 人物与空间 | 谁在场或离画，每人的位置、坐站姿态、朝向和视线，人物互相能看见什么 |
| 动作与物件 | 动作还没开始、正在进行还是已经完成，哪只手接触什么，物件到了谁手里，门扇、杯子、屏幕等处于什么状态 |
| 剧情与知情 | 哪个事件已经发生，人物已经知道或误会什么，观众已经看见哪条线索，下一镜才该揭示什么 |
| 对话与声音 | 说话人与受话人，最后一个已经说过的字句，下一句的起点，是否跨镜延续，同期动作声和持续底声 |
| 情绪与表演 | 角色的情绪与全场气氛，写得出来的身体信号，下一阶段的情绪是否已有触发点 |

用原文、现有画面或提示词确认能观察到的事实。某个状态未提供时，可用已经出现的动作、构图或环境承接。先区分世界里发生了什么和当前镜头拍到了什么。视角改变会改变画面左右、裁切和遮挡，人物在场景里的实际位置与动作仍需接续。

## 根据差异决定插什么

- **两端状态一致。** 保留同一姿态、位置、光线与动作阶段。根据场戏需要缩紧景别，补一个反应、局部细节或有意义的停顿。要拍环境或其他人物时，沿用已建立的空间和声音，切回时检查原人物的状态。
- **动作跨镜进行。** 从前镜交出的动作阶段继续，做到后镜需要的阶段即可。例如前镜门刚推开一条缝，后镜门已半开，新镜可以让原来的手继续推到半开。若后镜开头还要表现门达到半开，就把达到该位置的动作留给后镜。
- **状态确实不同。** 给变化留出动作与时间。坐到站可以用撑起、重心上移、站稳交代。若切去拍别处，回切后要有原文依据及能理解的声音、位置变化或结果来支持离画期间发生的变化。两端都坐着时，出入镜按坐姿承接。只有场戏本身需要起身再坐下，并且有足够时间展现或建立这段过程时，才安排这组动作。
- **从一个情绪转到另一个情绪。** 补已有剧情中的触发，再给反应。后镜才第一次揭示线索时，插镜可以拍等待、视线或局部预兆。认出线索后的表情安排在揭示之后。
- **跨时空或切其他行动线。** 保留两条线各自的时空、对白与动作进度。可用已有的视线、声音、形状或地标作衔接。切回原地点时，从原动作的下一阶段或有依据的时间推进继续。

## 常见例子

### 两端都坐着，插一镜反应

前镜末尾，林遥坐在窗边长椅上，右手按着票根，话已说完，窗外雨声持续。后镜开头，林遥仍坐着，同伴准备开口。

可以插「特写林遥按住票根的右手，指尖沿纸边滑了一小段后停住。雨声持续，同伴在画外有一次短促吸气」。也可切同伴的沉默反应，随后接原有开口。留住坐姿、票根的位置和雨声，等后镜开始原有对白。

### 递物尚未完成，补中间阶段

前镜末尾，信封还捏在递出者指间，另一人的手已经抬起。后镜开头，接收者指尖贴到信封，下一动作是接过后转向桌面。

插镜写「从侧面拍两只手靠近，递出者顺势把信封前移，两人指尖之间只剩一小段距离，递出者仍捏住纸角」。接触、交接和转向桌面的动作按后镜的原有进度发生。

### 对白跨切点，插一镜听者

前镜的说话人已经说出「门开了以后」，后镜起始仍保留他接着说「再把灯打开」。插镜可拍听者的眼睛移向门，留出停顿和走廊底声。后镜接后半句。若剪法允许后半句声音提前进入插镜，把该范围明确为同一次画外对白，并同步调整后镜的发声位置；顺播时整句话只出现一次。

### 情绪改变由剧情触发

前镜末尾，长椅上的人听见门响，食指扣紧票根。他在后镜开头已经认出同伴，肩膀放松。原文在中间写了同伴把熟悉的红围巾搭到椅背。插镜可先看到人物的视线落到围巾，再拍手指松开。下一镜仍从坐姿和放松的肩线接入。若围巾原本要到后镜才揭晓，可把插镜收在听见门响后的等待和视线转移。

### 空间与环境声一起过门

前镜末尾，人物站在雨中的屋檐下，手已按到门把。后镜开头，人物进了屋，门已经关上，室内只有微弱钟声。可以补一个从外拍门打开、人物迈入的画面，随后听见门合上，露天雨声被门压低，室内钟声接起。若后镜开头要拍关门，插镜结束时人物刚进门，关门声和雨声变化留给后镜。

## 修订范围内的检查

每改一个位置，顺读两端的提示词，核对道具归属、动作阶段、对白是否已说过、情绪是否已有依据。一个修改牵动整段镜号或时间轴时，重新核对受影响的区间。发现两端在同一时空给出无法同时成立的状态时，标出具体差异，再查原文或成片能否解释；需要改原有端点时，指出最小改动及它会影响的镜头。
