# 二维赛璐珞

适合以二维线条、成片色块和明确阴影表达角色。角色外形、背景分层与动作姿态可以保持清楚、节奏鲜明。

## 写法

- **线条。** 轮廓要能辨认，脸、手和衣物保留需要的内线。前景和主体可以比远景更有线条重量，环境细节按景别取舍。
- **色块与阴影。** 用清楚的固有色和一至数层阴影表现体积。光源变化可用阴影边缘和亮色区域的移动来表达。需要柔和气氛时，可让背景层比人物处理得更轻。
- **空间与表情。** 把前景、人物层、背景按原布局分开。正反打时沿用发型、领口、眉眼和配色。情绪发生变化时，用能辨认的表情和姿势承接。
- **视频表现。** 可用明确的预备、动作和停姿表现节奏。移动镜头时，前后景可出现不同速度的位移，并沿用同一空间关系。

## 示例

- **生图。** 二维赛璐珞动画画面。短发女子站在雨棚边，发梢、下颌和深绿外套用深色轮廓线勾清。外套用深绿平涂，脸侧的蓝灰阴影有清晰的硬边，暖黄灯光落在下颌的一小块亮面。雨棚前柱、人物和浅灰候车室形成三个清楚的画面层次。
- **生视频。** 二维赛璐珞动画。雨棚下的短发女子慢慢抬眼，发梢和深绿外套的描边清楚，衣服用平涂色块塑形。棚外暖黄灯光扫过下颌时，蓝灰阴影的硬边顺着脸部轮廓移动。镜头侧移，前景栏杆掠过，候车室在后方缓慢移动，前后景保持各自的线条和色块。
