# 构图

先确定观众第一眼要看到谁或什么，接着视线要被引向哪里。再考虑主体的大小、画面位置、前后景、遮挡和留白。场景参考图以看清分区、出入口和道具位置为先。人物参考图以辨认轮廓、五官、服装或动作需要的部位为先。带明确镜头目的的首帧或剧情画面可用更有叙事意味的裁切、遮挡和留白。

把构图名称落实到房间边界、物件、光区或人物的位置，示意图上的辅助线用于判断这些相对关系。多种构图可以共用，例如以中心轴安排走廊，同时用门洞框住远处人物。

## 构图写法

- **三分法。** 人物或关键道具靠一侧三分位置，另一侧留给视线、去向或第二个信息点。地平线放在上三分或下三分，按环境与前景哪个更重要选择。
- **中心对称。** 让门、阶梯、柱列或两侧人物沿中轴平衡。主体可位于轴心，或通过轻微偏离轴线打破原有秩序。
- **对角线。** 用楼梯、屋檐、长桌或明暗边沿从近处斜贯至远处。把关键人物放在斜线起点、转折或终点，使方向有可见依据。
- **十字形。** 用一条竖向轮廓和一条横向轮廓在重点附近交汇，例如廊柱与窗台、人物躯干与伸开的手臂。保留交点周围可辨的明暗关系。
- **L 形。** 让立柱、侧墙等从画面一侧向上延伸，台阶、窗台或桌边沿底部横向延伸。可把主体放在转角，或让空出的一侧承担视线方向。
- **S 形。** 用河湾、蜿蜒路面或几处错位的人物串成两个弯，把近处细节依次带到中远景。保持弯折处的遮挡关系和尺度递变。
- **圆形。** 用拱窗、围坐的人群、旋动的叶片或环形的布景围出中心。主体可在环内活动，明暗足以让环形与背景区分。
- **金字塔。** 将较宽的一组人物或物件压在画面下部，两侧向上收拢，在尖端放关键人物或最高点。层级可由站位、台阶或光区体现。
- **放射线。** 让廊柱、墙缝、地砖和灯带朝同一消失点收拢。把叙事重点放在消失点附近，也可让人物走过中轴改变视觉重心。
- **黄金螺旋。** 用连续弧线、大小递减的形体或前后错位的遮挡形成回旋路径，让视线逐步收向一个小而明确的重点。
- **框架。** 利用门、窗、桥洞或较近的暗色物件在画面内部围出视野。说明被框住的主体及框内应保留的背景信息。需要观察表情时，可让遮挡避开眼睛和嘴。
- **水平线。** 用地平线、水岸线、墙裙或远处建筑形成稳定横向基准。把水平线放高可多给前景，放低可多给天空或建筑体量，单独处理主体与横线的交叠。

## 写进图片和视频

- **生图。** 描述主体所在区域与前后景如何相接，例如「人物站在画面右三分处，左前景的窗框形成一圈深色边，窗外的路往右后方退，让视线跟到远处灯下」。独立场景图可留出需要在后续视频中走位的通道。
- **生视频。** 在动作起点和终点各确认一次构图。侧移或跟拍时，可以让遮挡逐步打开，或让人物移到新的视觉重心。比如「开场门框左侧遮住部分庭院，镜头向右移，人物从框内右侧走到亮处，左边露出通往庭院的台阶」。
