# 选参考与制作参考素材

## 先找这一段最容易失控的变量

逐段从角色身份、空间、道具状态、画面节点、运动、风格和音频中选真正需要外部约束的变量。现成素材能解决就复用。词语能稳定描述的环境或偶发动作可直接交给文字。

- **纯文本。** 适合单场景、一次性角色、固定机位、线性动作或视觉探索。用主体外形锚点、起止站位和一条主动作写清场景。已有角色跨段复用时，用经过确认的主体图做视觉基准。
- **主体参考。** 同一角色跨段、换机位、换服装，或多人容易串脸时，每人先用一张清晰身份图。需要背面认衣纹或连续正反打再补独立角度。同一个人物的多张图须声明为同一身份。关键道具因开合、移交或损坏决定剧情时，补道具参考和它的叙事状态。场景反复出现、人物进出方向影响因果或正反打涉及空间时，准备场景空镜主视图。需要有声身份时，用对应角色的干净音色样本配主体图，或使用合适的主体音视频。声音和图像各绑定到具体角色。
- **风格参考。** 图片适合锁定色温、反差、材质、光线和画面质感。视频适合参考动态曝光、运动质感或有规律的光影。把风格样本和主体分别绑定。优先选没有会被误认成目标人物、文字或道具的样本。
- **宫格故事板。** 要给模型交代镜头顺序、构图大势、景别节奏或关系走向，同时允许画面自由发挥时使用。全段 10–12 格即可，按固定阅读顺序排列并在文字中对应。官方经验适合少于 15 格。选简洁线稿或火柴人，在整数秒时间轴写清每镜起止，并补充角色身份、动作方向、表情、运镜、台词、声音、灯光与转场。概念分镜只需要提供情节和整体方向时可简写素材说明，仍保留逐镜时间轴。
- **顺序关键帧。** 剧情依赖道具出现的一刻、人物在指定位置的揭晓、门内外构图的切换等关键画面时，为这些节点制作独立图片。按时间顺序上传，提示词首个内容句列出顺序，把图绑定到相应时间点或镜头。关键帧是视觉锚点，仍需写运动路径和画面怎样从上一个节点演进。素材预算有限时优先保住不可替代的锚点，其余镜头用文本完成。
- **多图参考中指定首帧。** 需要同时参考人物、场景和开场构图时，保持多图参考模式，首帧图与其他图一起作为普通参考图上传。按上传顺序编号，可在场景描述开头写「使用 @图片X 为首帧图。」然后注明其他图片的用途。例如「使用 @图片3 为首帧图。@图片1 用于人物外貌与服装，@图片2 用于场景布局。」首镜描述图 3 的构图、人物站位、姿态和接续动作。指定图为开场提供柔性参考，输出画幅可以独立设置。
- **正式首帧或首尾帧。** 画面必须从某张指定图动起来，或必须抵达一张指定终局图时使用。优先复用已验收上段的尾帧，用前一段角色姿态与背景光色对齐新段。首尾图应同画幅，叙事中间要有合理动作。若还需同时控制中段关键画面或混合多个其他素材，先核对工具是否支持组合。否则用顺序关键帧取得近似对齐，或把严格首尾与其他需求安排在后期。
- **运动与运镜参考。** 根据需求选择动作、表情、物件轨迹、镜头或某项特效的干净视频。明确起止时间、采用的运动和方向，身份、服装、背景、声音按本段设定约束。运动讲不清时优先短视频。只需知道人该走到哪时用白模。只需一个静止构图时用图片。
- **白模参考。** 当走位、物体轨迹、机位视差、时序或遮挡关系必须一起稳定时，用简单几何体或色块搭建。用颜色和位置为主角、道具、场地留可识别标记。要复刻完整重渲染时可用细粒度白模，清理坐标轴、轨迹线、相机图标、辅助网格。粗白模无需制作僵硬的手臂、翅膀等部件，已经出现的细肢应有连贯运动。明确白模负责的镜头、时序、轨迹、遮挡及灯光变化，然后绑定实际角色和场景。缺图的主体用文字补外形。
- **音频参考。** 跨段音色要稳定时用干净单人样本，卡节奏时用音乐素材并指明时间或重拍；要求读准特定台词时以原文和清晰干声为锚点。明确采用声线、旋律、节奏或完整对白中的哪项，背景杂音、说话内容与画面用途按需限制。与口型精确同步是验收目标，生成后仍需核对。只有声音参考且没有图像时，官方 2.5 系列也可提交，确认宿主入口是否支持。
- **已有成片。** 保持原视频的大部分画面并修改局部，用编辑。只为下一段保持视觉一致，可提取末帧做首帧或作为普通参考。需要从现有视频头尾自然添加新内容，用延长。两段已存在，中间缺过渡时，可提取出点和入点作首尾或顺序关键帧，明确匹配的是运动、构图、色彩还是声音，再把该过渡编入所在 30 秒成片。

## 哪些图应该先做

先定内容范围和风格，再制作可复用的资产。临时设计只补原文未规定、且出图必须决定的细节。前后保持同一版设计。 结合后续镜头需要延续的人物特征和空间关系，选择合适的构图、景别与视角，把相关细节写成具体的画面描述。

1. **角色基准图。** 建立每位主角本场的脸型、年龄观感、发型、体态、衣着层次、辨认标志。先做干净背景的三分之四全身或中全景。五官或手中动作特别重要时补脸部近景或局部道具关系。多个角度必须沿用基准图生成或保持同一外观。 画面要突出表情时可用近景。体型、服装或姿势对后续镜头重要时，让相关部位完整入画。配饰或手持物影响剧情时，可用局部构图，选择能辨认细节的角度和光线。背景按人物轮廓和用途选择，需要交代人物与环境的位置关系时，可保留相关景物。补不同视角时核对身体比例、当前剧情阶段的服装和配饰。
2. **场景基准图。** 做无人全景，写清出口、门窗、前后景、可走路线、关键道具位置、主光方向与天气。需要反打轴线时再做对侧构图，确保门窗与家具相对位置一致。 室内可补写家具、通道和人物能站立的位置，室外可补写路径、地标、高低差与进出方向。人物、车辆或物件影响走位时，可以保留在场景图里。换入口或需要交代遮挡区域时，可补对应视角，并结合可见地标核对空间布局。同一地点在不同时段复用时，可沿用空间轴线与主光方向，按剧情调整光线和天气。
3. **道具状态图。** 需要识别或影响行为的物件做单物图，并提供容易混淆的开合、亮灭、正反、干湿或完整程度。要看清原文关键字时先把准确文字做成干净图形并查字。将手持方位和实际尺寸写进镜头脚本。
4. **风格图。** 用户留空就不自行设定可见风格要求。用户明确风格或批准视觉方案时，选择能代表光线、材质、画面色域的一张基准，跨段复用。
5. **段内关键帧。** 借角色、场地和道具基准图做首帧、关键反应或揭晓帧、尾帧。每帧指定镜头区间、景别、机位、人物画面位置与视线、动作进度、道具归属、光线。先做下一段会复用的接点，再补段内独立关键画面。需要预排镜头顺序、景别和大致节奏时，可另做一张线稿宫格，格内用清楚轮廓和可读的运动方向，格外用提示词管理顺序。
6. **动态与声音参考。** 静图验收后再做走位、运镜样片、白模或音频。一次以一个目标为主。用户要求全流程且工具可用时直接推进已授权的生成，合格后才进入下一步。

### 可直接执行的素材提示词骨架

- 角色图写人物身份与当前服装 → 外观锚点与明显标志 → 机位和景别 → 自然站姿与手部 → 干净背景和可辨面光。补视角时明确沿用同一身份、服装、配件和比例。
- 场景图写时间地点 → 空间坐标与进出方向 → 前中后景和道具位置 → 天气与光源 → 无人构图。场景轴线和光源可延续至同地点其他时间段。
- 道具图写材质颜色与比例 → 叙事状态 → 可辨细节 → 中性背景与拍摄角度。必要时列一张状态前图和一张后图。
- 关键帧图写引用的基准素材 → 当前故事时刻 → 静止姿势与手部状态 → 空间坐标、视线和机位 → 画幅、光照与焦点。每张图表达一个确定瞬间。
- 线稿宫格写统一画幅和阅读顺序 → 每格景别、视点、人物相对位置 → 一格一个明确动作节点 → 干净线条与留白。格间边界仅用于阅读。需要在成片显示的文字另做素材。
- 运动或白模写参考对象 → 唯一主轨迹或机位运动 → 时间与起止位置 → 所需的停顿、遮挡或落点 → 封闭干净的输出背景。音色样本写角色、语种、口音、音区、语速和录音环境，采用可用的授权来源。

### 资产验收、命名与绑定

- 内部清单至少记稳定名称、版本、具体职责、叙事状态、适用视频段、真实路径或素材 ID。提示词里的 `@图片1`、`@视频1`、`@音频1` 是每次实际请求的类型内编号，从 1 开始，依据上传顺序重新分配。长期资产名用于复用，相同资产在下一段可以有不同的引用编号。
- 多人素材按首次出场顺序整理。逐一核对谁的外形、服装和声音绑定在一起。同一参考只在已验收的维度承担职责。对部分片段标出时间和主体，避免同一元素有冲突参考。后续插入、换序或删除文件时同步更新所有引用。
- 看一遍参考图中脸与手、角色数量、道具状态、相对站位、光源、画幅及标注痕迹。听音频是否干净、声线和语种是否正确。尽量使用无字幕、无水印、无多余声道的参考视频。题材和上传素材必须符合平台与用户的合规要求。
- 参考图适合少量主体，官方经验为主体图先用 1–8 个主体，主体音视频先用 1–5 个主体、单份 5–10 秒。超过 5 个主体时优先单视图，需要多角度就分为独立图片。9–12 个主体图对应的主体、6–10 个音视频主体属于稳定性较低的尝试，也要服从当前模型素材上限。
- 资产未生成时可把它写为制作任务和制图提示词，交付文本中的素材引用只从实际有文件可供上传的清单产生。若用户暂时不做素材，用可见描述把缺失的关键信息写进时间轴。
