# 方舟执行与成片校验

本文件把方舟规范用于小说分镜。先判断当前请求是交付提示词、生成参考素材还是生成成片。能力与参数依据《Doubao Seedance 2.5 系列提示词指南》2026-11-24 版，并结合《Doubao Seedance 2.5 系列教程》《创建视频生成任务》。不同接入工具可能只开放部分能力。

## 按意图选任务

- **文生视频或普通参考生视频。** 做一个全新段落时，可纯文本提交，或使用 `reference_image`、`reference_video`、`reference_audio` 绑定素材。宫格和顺序关键帧均可作为普通图片参考。它们允许配置目标宽高比与时长。创建小说新段时填 `duration=30`。当工具暴露子任务字段且输入含视频时，明确选择 `omni_reference_task_type=reference` 以表明是新生成。单纯复用外观、表演、轨迹或剪辑节奏都可走此模式。
- **首帧和首尾帧。** 使用专用的 `first_frame` 和可选 `last_frame` 角色，按当前工具允许的组合接入。2.5 系列只用 `ratio=adaptive`，画幅跟随首帧，尾帧提前对齐画幅。时长可选 30 秒。普通参考中用文字声明哪张是首尾画面的控制较柔性，适合还要多模态参考或独立设置画幅的段落。
- **编辑。** 明确哪一支是原视频、修改起止秒、人物或区域、原状态和目标。例如，在 @视频1 的 12–15 秒把窗外光由白色改为琥珀色，使台词、表演、室内摆设、切镜和其他声部沿用原片。用 `edit` 子类型（工具支持时）、`ratio=adaptive`、`duration=-1`，时长由源视频锁定，画幅随视频。外部原片的编辑输出可能因帧处理略短，按媒体实测时长判断。多视频输入时把待编辑源和参考源分开指明。先从少量参考图入手，官方经验以 1–5 张及 20 秒以内的源片较稳。需要用 6–8 张时先检查重复和冲突，按稳定性较低的输入处理。增加、删减和替换可包含主体、服装、背景、局部材质、机位和特效，也可单独修音频的人声、音乐和音效。需要新外观时加参考图并指明原视频里的局部。仅开放自动判定时，把“编辑 @视频1”和增、删、改指令写在开头。已有 30 秒影片仍可编辑，修改后实测最终交付时长。
- **延长。** 使用 `extend`（工具支持时），`ratio=adaptive`。指明向前或向后延长哪支视频，有主体图时写清延长部分人物的引用。仅开放自动判定时，把“向后延长 @视频1”或相应方向写在开头。写清对应接点的姿态、动作相位、镜头方向、局部光影、声场与新内容。具体输出时长按入口配置，用剪辑确认是否要把原视频和新生成部分拼接。用户只要求独立下一段时，应按段安排 30 秒并做可独立的首镜，不为所有段落默认开启延长。编辑和延长可在支持时选择 MOV，延长输入输出同用 MOV，有助于色彩、亮度和声音衔接。优先使用已经验收的 2.5 原片续接，拼接时检查两端的音量。
- **多图短片与转场。** 素材本身已经覆盖故事动作时，可给多图写出镜次序、入镜方式与声响，可只用多张相片、混合图片和片段，或再给一支参考视频控制剪辑节奏。低运动量场景可让光影和物件轻微变化。标题、贴纸、配乐和转场仅按委托内容添加。接两个已验收镜头时，明确前片出点、后片入点、共有的形状或方向和中间动作。按需求生成桥接或做后期合成，让过渡占用现有 30 秒时间轴内的预算。

## 提交前的能力检查

- 输入上限以当前型号和工具为准。方舟 Seedance 2.5 每请求至多 30 图、10 视频、10 音频，flash 为 10 图、5 视频、5 音频。视频参考的合计时长上限 30 秒，参考音频另计总计 30 秒。非编辑参考视频和单段音频通常为 2–30 秒，编辑源为 4–30 秒。静图、视频和音频优先选择入口支持的格式，例如 PNG/JPEG、MP4/MOV、WAV/MP3。普通生成可选 4–30 秒。不同入口的保存时效、上传大小、输入格式及分辨率可能有差异，每次使用前核对。
- 实际生成前按宿主能提供的能力说明核对模型标识、任务类型、时长、参考数量、宽高比、声音与角色字段。核对角色名、素材编号与提交文件一一对应。入口不支持 30 秒直出时，保留完整 30 秒镜头设计并说明限制。用户要求制作成片且工具允许时，可按镜头边界内部拆任务再拼合，交付仍是一段 30 秒、10–12 镜。避免在台词中间或不可匹配的高速动作处切子任务。用户明确要求一次直出时，以实际入口能力为准。
- 人物参考图或视频按平台的肖像规则提交。方舟 2.5 系列不接受直接上传带真实人脸的普通参考素材。作品需要真人肖像时使用平台支持的已授权素材、预置虚拟人像或合规的原始生成产物路径，结合当前入口权限核查。
- 方舟推荐按主体、动作或事件、环境、风格、镜头和声音组织，模型响应整数秒时间戳。镜头区间写连续，固定约束只写一次，精确素材简洁指代。接口建议中文提示词控制在 500 字以内、英文在 1000 词以内以集中注意力，此为篇幅建议。先压缩重复环境、运镜形容和外貌复述，保留 10–12 镜、角色的原文台词、接镜状态与关键声画信息。不能压缩时重分配情节，再按完整 30 秒设计。
- 有声段使用接入工具的声音开关（方舟为 `generate_audio`）。优先保留分镜模板的 `『』` 和声音字段。需要适配方舟符号时，提交文本可用 `{台词}`、`<音效>`、`(音乐)`、`〖字幕〗` 作声音指令，并确保同一句只提交一次。字幕仅在用户需要时使用；字幕、画内字、配乐、对白和音效分别指定。有非中文对白时明确角色发音语言和口音，原词按原文照录。

## 失败时先诊断再调

| 观察到的问题 | 优先操作 |
| --- | --- |
| 串脸、角色复制、音色错接 | 检查上传顺序和 `@` 类型编号，按首次出场顺序排列。每位角色先只用一张图和单人声线，复核与台词一致。 |
| 正常情绪生成发光瞳孔 | 把情绪改成可见的眼睑、下颌、呼吸和面部动作。写自然瞳孔，把彩光约束到面部轮廓或环境。 |
| 台词、镜头漏掉，宫格静止或乱序 | 减少重复指令和冲突参考。给台词留足读速与换气。宫格改简洁线稿，关键画面改用独立关键帧。 |
| 字幕总出现 | 检查参考视频是否有字幕，改用无字幕源。把对白定义为音轨，在全局明确画面无字幕，区分画内文字。语气放在角色开口前，避免在对白后重复原词。 |
| 画内文字拼错 | 英文短字标可逐字母写顺序，短中文可用正确字形图。重要标题、牌匾或长文本制成准确的参考图，或在后期叠加。 |
| 仍生成背景音乐 | 写清只保留哪些声源和音效。需要时首尾明确排除配乐、旋律和器乐铺底。若使用后期提取人声，会损失环境或动作声，按需重建音效。 |
| 出现水波纹、气泡或回声噪声 | 删去无叙事必要的水、波浪、回音等词。必须保留该场景时锁定实际需要的声源，使用干净参考或后期处理。 |
| 翻译后残留原语或口型错误 | 仅在用户要求翻译时使用。列完整目标语言时间轴、角色及背景里可辨别的低语、感叹、语气词；检查原语残留、目标语言口型、字幕和混音。 |
| 特殊 JPG 无法解码 | 文件扩展名正确时仍可能采用非标准色度采样。用图像工具转 PNG 或标准 4:2:0 JPEG 后重新导入。 |
| 纹理像指纹或鞋印 | 草叶等密集纹理使用过高分辨率参考图时更容易出现。把参考图缩至输出分辨率以内。有条件可对比 1080p 与 720p。 |
| 复杂任务互相干扰 | 把角色、动作或特效先生成可验收的参考片，再对源视频做局部编辑。每次改变一个关键变量，保留验收过的素材与镜头。 |
| 编辑输出比源视频稍短 | 检查帧数和音视频时长。必须做严格局部编辑时先保留编辑模式，方舟还给出 8n+1 帧整形案例，可用于测试；严格 30 秒成片最终在剪辑中做无信息损失的裁切或补齐。允许画面差异时可改用普通参考并指定时长。 |
| 2.0 与 2.5 风格不一致 | 同一参考与提示词在两代可能有不同的美学表现。需要延续旧画面时，用已验收的 2.0 原片走 2.5 延长，选择 MOV 并复查色调、亮度和声音。 |
| 编辑时更换画幅导致画面失配 | 需要改画幅时用新画幅的普通参考生成或后期重构图。普通参考中逐镜写原片构图顺序、动作轨迹、剪切点、对应节奏和新增画幅边缘如何延伸。 |

问题及方案按方舟 2.5 创作指南的常见问题章节整理。

## 实测成片

若要求实际视频，逐段用播放器、剪辑工具或 ffprobe 检查真实呈现时长、轨道和帧率。API 的 duration 字段可能是向下取整的秒数，不能替代媒体实测。核查画面是否为所写 10–12 镜、台词语序和口型、人物位置、道具状态与衔接。检测首尾停顿、声音跳变和不合规画面。小范围修改先考虑局部编辑或后期，画面整体失配再调整参考和提示词重试。保存已通过版本、实际素材引用与生成状态。在未取得成片时只报告提示词或素材是否通过对应的检验。
